# ViewVolume

3次元のNumPy/TIFFボリュームデータを表示する、TkinterとMatplotlibを
使用したビューアです。

## 入力データ

入力データは、形状が`(z, y, x)`の数値型3次元配列である必要があります。
対応している拡張子は`.npy`、`.tif`、`.tiff`です。

## 起動方法

`CT_Viewer/src`フォルダで、入力ファイルを指定せずに起動します。

```powershell
python -m ViewVolume
```

起動後、**LoadData**ボタンから`.npy`または`.tif`ファイルを選択します。
**Register pointer**で座標を登録し、**Finish**を押すと、選択座標が
`(x, y, z)`の形式で出力されます。

## 操作方法

- 平面選択メニューから`axial`、`sagittal`、`coronal`を選択します。
- スライダーまたはスライダー上でのマウスホイール操作でスライスを移動します。
- 画像をクリックしてpointerを選択し、**Register pointer**を押します。
- 登録後に**PeakLocalMin**を押すと、登録座標を起点に局所最小を探索します。
- 探索結果の局所最小座標は登録座標とは別に保持され、青色のクロスヘアで表示されます。
- pointerを選択した状態でCtrlキーを押しながらマウスホイールを操作すると、
  選択したpointerを中心に拡大・縮小します。
- ヒストグラム上の2つのハンドルをドラッグすると、表示するWW範囲を調整できます。
- z方向のフレーム数が1の場合、平面選択メニューとスライダーは無効になります。

## 座標系

- Axial: `volume[z, y, x]`
- Sagittal: `volume[z, y, x]`、`x`を固定
- Coronal: `volume[z, y, x]`、`y`を固定

GUIから返される座標は、常に`(x, y, z)`の順序です。

### 局所最小探索

**PeakLocalMin**では、登録座標を起点として、各軸±3の7×7×7近傍を
探索します。中心ボクセルを除く最大342個の候補から、現在値より小さい
ボクセルへ移動し、移動できなくなった座標を局所最小とします。

背景ボクセルは、次の条件を満たすボクセルです。

- 自身の画素値が0
- 26近傍のうち、画素値0のボクセルが9個以上

背景ボクセルは局所最小の候補から除外されます。
