## 画像処理研究会発表
咬合のデータではうまくいかないことから、他のデータでやってみてはどうかとアドバイス
以下の要領で進めることに
- いい感じのデータでは、理想通りのものが出力されるのか。
   - 今回の手法と同じで、適当な1スライスでラベリングするようにする
- いい感じのデータが量産できれば、それをもとにセグメンテーションするモデルを作成する

### 仕様
- input 画像
  - 重みづけのした元データ
  - seed画像
  - mask画像
- 重みづけのした元データ
   - 元画像を距離変換した画像
- seed画像
  - ラベリングされた画像
    - 同一の歯は同一のラベリングがされていること
  - seed の準備
     - 提案手法1
        - 1.  前肢
     - 提案手法2
        - 1. ImageJ で1データ1歯でのアノテーションをする (黒)
          2. 二値化して反転する(背景+アノテーション領域を255にする)
          3. 連結成分を抽出する
          4. すべての成分を同じ値にする (1データ1歯のため)
